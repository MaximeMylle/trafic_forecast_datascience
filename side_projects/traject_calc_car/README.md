# Traject Calc Car (Side Project)

This folder contains all files that belong to the separate `traject_calc_car` side project.

## Folder layout

- `data/raw/traffic_car/`: source files (xlsx/xml)
- `data/processed/traffic_car/`: processed CSV files
- `notebooks/`: analysis notebook(s)
- `reports/figures/`: exported charts
- `docs/analysis/`: analysis notes and handouts
- `docs/presentations/`: presentation files and assets

## Quick start

Open the notebook:

```bash
jupyter notebook side_projects/traject_calc_car/notebooks/Analyse_historical.ipynb
```

## Notes

- This structure keeps side-project files isolated from the main project flow.
- Files were moved with git history preservation (`git mv`).
